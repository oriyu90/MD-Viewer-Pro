# 欢迎使用 MD Viewer Pro

可以在顶部工具栏切换模式、版式和缩放等。

## 功能一览

功能 | 说明
---|---
阅读模式 | 清晰地渲染 Markdown
MD编辑 | 保持渲染后的样子直接编辑
TXT编辑 | 左侧编辑器 + 右侧实时预览
A4文档 | 适合打印的 A4 版式与页边距
设置 | 字体、语言、主题、加粗样式的选项
插件主题 | 在 ~/.mdviewer/themes/ 放入 JSON 文件即可添加配色

## 清单

  * Markdown 渲染
  * 实时预览
  * 代码块的复制按钮
  * 导出 PDF / HTML
  * 插件主题
  * 云端同步（计划中）

## LaTeX 数学公式 (v1.4.1)

行内公式用 `$…$`，独立成行的公式用 `$$…$$`。

爱因斯坦的 $E = mc^2$ 可以自然地写在句子里。

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

$$ \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \qquad \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2} $$

$$ A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \quad
f(x) = \begin{cases} 1 & (x > 0) \\ 0 & (x \le 0) \end{cases} $$

支持分数、根号、矩阵、cases、可自动伸缩的括号、`\mathbb{R}` 等字体、
重音符号和希腊字母。代码块与行内代码中的 `$` 不会被当作公式，
`$5 和 $10` 这样的货币写法也会原样显示。

## YAML (v1.4.1)

文档开头用 `---` 包围的部分，会作为前置元数据面板单独显示。

    ---
    title: 文章标题
    tags:
      - markdown
      - latex
    ---

也可以打开 `.yml` / `.yaml` 文件（语法高亮，阅读 / TXT编辑）。

## 添加字体 (v1.4.1)

在「设置 →字体」中可以从推荐字体、已添加的字体和系统字体中选择。
「添加字体...」会把 TTF / OTF 文件导入到 `~/.mdviewer/fonts/`，
下次启动后仍可使用。「删除所选字体」只会删除自己添加的字体。

## 换行的处理 (v1.4.2)

用 Enter 输入的换行会直接显示为换行。如果需要标准 Markdown 的行为，
可以在「设置 →换行的处理」中关闭。

## LaTeX 版式命令 (v1.4.2)

`\newpage` 等描述版式的命令不会显示为文字，而是作为指令反映到显示上。
导出 PDF 时会真正在该处分页。
