# MD Viewer Pro β2.1 — ツールバーとダイアログを v1.5.3 の形へ

Python/PySide6 版 v1.5.3 の QSS と寸法表をそのまま写して、上部バーとポップアップの
「形」を作り直しました。

## 変わったところ

- **メインツールバー**: ボタンが 72px を満たす `#1c1c1c` のブロックに。文字は 17px 太字、
  区切りは 1px 全高。`#0c0c0c` が見えるのはスケール欄だけになります
- **幅の配分**: 旧版と同じく、余った幅を全ボタンへ均等に配分（右端まで届く）
- **書式ツールバー**: 背景 `#111`・15px 太字・hover は青地に白文字
- **ポップアップ**: 角丸を廃止し、1px 枠＋QGroupBox 風の「枠線上のタイトル」に統一。
  入力欄は角丸 4px、ボタンは全て同じ形（青い主ボタンは廃止）
- **チェックボックス**: macOS の丸いものではなく、アクセント色の角丸四角＋白チェック
- **本文**: 見出しの下線を廃止、行間 1.8、左右余白はウィンドウの縦横比に追従
- **水平線・コード・引用・表**: 旧版の色と角丸に合わせて調整
- **スクロールバー**: 7px の細いバー
- **サイドパネル**: 見出し 20px、項目 16px。クリップの「＋追加」は見出しの下へ
- **起動時**: 背景のウェルカム文を廃止（ダイアログだけが出る旧版と同じ状態）
