# MD Viewer Pro β3.0 — 文字を明るく太く、表のボタンと目次を直す

## 変わったところ

- **配色**: ダークは黒背景に白文字になりました。灰色はかなり明るい `#b3b3b3` までとした
  （本文は `#f5f5f5`）。ホワイトモードは逆に、淡い灰を暗めの `#636363` に
- **フォント**: 本文とエディタを 600 の太さに。アプリ内の文字全体も同じく太くしました
  （v1.5.3 の太字表示に合わせた形）
- **アイコン**: macOS の丸角標準（squircle）に作り直しました。1024px・図柄はセーフゾーン内。
  従来の四角で隅まで一杯だった形は廃止
- **説明**: 起動ダイアログを閉じて何も選ばなかったら、v1.5.3 の説明文面（「MD Viewer Pro
  へようこそ」）がそのまま開くようにしました
- **表**: MD編集で表の下に `+ 列` / `+ 行` ボタンを出します（v1.5.3 の `_mdvSetupTableBtns`
  をそのまま移植）。ボタンの見た目も青い輪郭・11px 太字で揃えました
- **目次**: 「閲覧モードでは出ない」問題を修正。設定の表示／非表示だけで全モード共通になり、
  ボタン 1 回のクリックで出入します
