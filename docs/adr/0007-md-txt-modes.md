# ADR-0007: MD編集とTXT編集を分離し、ブロック単位で原文へ反映する

- 状態: 採用（2026-11-01）。ADR-0005 を改訂
- 決定者: メイン（設計）

## 文脈

v1.5.3 は「MD編集（WYSIWYG）」と「TXT編集（ソース+プレビュー）」の 2 つの編集モードを持つ。
v26 では文書破壊を避けるため 1 モードに統合していたが、操作感の互換性が失われた。

## 決定

- 3 モード（閲覧 / MD編集 / TXT編集）に戻す
- TXT編集: 左ソース + 右プレビュー（従来どおり）
- MD編集: プレビューを contenteditable にして直接編集
- 保存・モード切替時に、**変更されたトップレベルブロックだけ**を Markdown へ逆変換して
  元の行範囲に差し替える（全文化の逆変換はしない）
- 行範囲は comrak AST の sourcepos から取得し、フロントマター除去分をオフセットする
- HTML→Markdown は Turndown（GFM プラグイン）を使用。数式は KaTeX の annotation から
  TeX を復元し、Mermaid は元のフェンスに戻す
- ブロック数が一致しない文書では安全のため反映を中止し、TXT編集を案内する

## 結果

- v1.5.3 と同じ 3 モードの操作感を提供
- 未編集ブロックはバイト単位で保持されるため、旧版のような全文書き換わりを避けられる
- 編集したブロック内の複雑な Markdown（入れ子リスト等）は Turndown の変換に依存する
