# ADR-0005: 編集は「ソース + プレビュー」に統一する

- 状態: 採用（2026-11-01）

## 文脈

旧アプリは 閲覧 / MD編集（WYSIWYG）/ TXT編集（ソース+プレビュー）の 3 モード。
MD編集は ADR-0002 の理由で維持できない。

## 決定

v26.0.1 は 閲覧 / 編集 の 2 モード。編集は左ソース（textarea + 行番号）、
右プレビュー（120ms デバウンス）。書式ツールバーは編集時のみ表示。

## 結果

- 実装・保守が単純化し、破壊的編集がなくなる
- 旧 MD編集の「見た目どおりに直接編集」は非対応（README に明記）
- 将来 CodeMirror 6 等へ差し替える場合も、状態モデルは source のまま
