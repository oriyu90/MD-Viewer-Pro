# 実装計画書 — MD Viewer Pro v26.0.1

- 版: 1.0（2026-11-01）
- 対象: `md-viewer-pro-rust`（Tauri 2 + Rust）
- 元アプリ: MD Viewer Pro v1.5.3（Python 3 / PySide6 / QtWebEngine / 7,915 行）
- 開発体制: メイン（全体監督・統合）+ サブエージェント（i18n 抽出 / UI スペック抽出 / レビュー）

## 1. 目的

1. 内部をほぼ Rust に置き換え、配布物・メモリ・起動時間を大幅に縮小する
2. 既存の UI・操作感・機能を維持しつつ、macOS ネイティブアプリとして自然に動く
3. 構造的な負債（HTML→Markdown 逆変換、全モード WebChannel、単一ファイル化）を設計で解消する
4. 回帰可能なテストと、再現可能なビルド・配布手順を備える

## 2. 非目標（v26.0.1 では扱わない）

- Windows / Linux の配布ビルド（設計は共通。macOS で先行検証）
- MD 編集の WYSIWYG（contenteditable）完全再現。v26 では「ソース編集 + プレビュー」に統一する
- モバイル（Tauri 2 の iOS/Android 対応は将来）
- クラウドアップロード（Google Drive / OneDrive）連携
- 自動更新（tauri-plugin-updater）の配信サーバー運用

## 3. 受け入れ条件（AC）

| ID | 要件 | 検証方法 |
|---|---|---|
| AC-01 | macOS で .app が起動し、ウィンドウが表示される | `open` 起動 + プロセス確認 + セルフテスト |
| AC-02 | Markdown（GFM: 表・タスクリスト・打ち消し・脚注）が描画される | 単体テスト + セルフテスト |
| AC-03 | 見出し ID と TOC が生成され、クリックで移動できる | 単体テスト + セルフテスト |
| AC-04 | フロントマターがメタ情報として表示され、本文から除かれる | 単体テスト |
| AC-05 | コードブロックがハイライトされ、コピーボタンが動く | セルフテスト + 手動 |
| AC-06 | 数式（KaTeX）と Mermaid がオフラインで描画される | セルフテスト（.katex / svg 要素数） |
| AC-07 | ファイルを開く・保存・名前を付けて保存ができる（原子的保存） | 単体テスト + 手動 |
| AC-08 | 設定（言語・テーマ・アクセント・フォント・文字サイズ・改行・余白）が永続化される | 単体テスト + 手動 |
| AC-09 | 5 言語の UI 文言が切り替わる | i18n キー一致テスト + 手動 |
| AC-10 | テーマ（ダーク/ライト/システム）とアクセント色が反映される | 単体テスト + 目視 |
| AC-11 | HTML 書き出しが単体で開ける | 手動（生成物をブラウザで開く） |
| AC-12 | PDF 書き出しができる | 手動（macOS 印刷ダイアログ経由）※制約として記録 |
| AC-13 | クリップボード（フレーズ集）が保存・コピー・削除できる | 手動 + 状態ファイル確認 |
| AC-14 | ドラッグ＆ドロップ・関連付け・単一インスタンスが動く | 手動 |
| AC-15 | 配布物（DMG）が ad-hoc 署名され、起動手順が文書化されている | `codesign --verify` + README |
| AC-16 | 起動時間・メモリ・サイズが旧版より改善している | 実測（`ps`, `time`, `ls -lh`） |
