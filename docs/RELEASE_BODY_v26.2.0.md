# MD Viewer Pro β2.0 — MD編集 / TXT編集の分離（26.2.0-beta.2.0）

v1.5.3 と同じ 3 モード構成（閲覧 / MD編集 / TXT編集）に戻した版です。

## 変更点

- **MD編集**: プレビューを直接編集（contenteditable）。書式ボタン（B/I/見出し/リスト/引用/リンク/表など）は DOM に適用
- **TXT編集**: 左ソース + 右プレビュー（従来どおり）
- 保存・モード切替時は**変更されたブロックだけ**を Markdown に戻して原文へ反映
  - comrak の sourcepos で行範囲を特定、Turndown(GFM) で変換
  - 数式は KaTeX の annotation から TeX を復元、Mermaid は元のフェンスへ
  - 未編集ブロックはそのまま保持（全文の書き換えをしない）
- ツールバーに 3 モードを表示（v1.5.3 と同じ並び）

## 検証

- 単体テスト 27 件 PASS
- 実 WKWebView E2E: MD編集で段落を変更 → 原文へ反映され、見出しは保持（`mdBlocks=5`）
- PDF 直接書き出し・目次・数式・Mermaid・保存往復も継続して PASS

## 既知の制限

- MD編集で編集したブロック内の複雑な入れ子構造は Turndown の変換に依存します
- ブロック数が一致しない文書では安全のため反映を中止し、TXT編集を案内します
