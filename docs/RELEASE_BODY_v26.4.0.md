# MD Viewer Pro β4.0 — 標準アプリとして開ける・TXT は TXT のまま・ツールバーがなめらかに

## 変わったところ

### 1. Finder の標準アプリとして使えるようになりました

- `.md` / `.markdown` / `.mdown` / `.mkd` を **Markdown 文書（Owner）** として宣言し、
  `.txt` を **プレーンテキスト（Editor）**、`.yml` / `.yaml` を **YAML（Viewer）** として
  別々に登録するようにしました。旧版は 1 つの書類型にまとめていたため、
  「このアプリケーションで開く」に正しく出ないことがありました
- Markdown の UTI（`net.daringfireball.markdown`）をアプリ自身で宣言（旧 Python 版と同じ）
- **起動時にファイルを渡されたとき、開かずに起動ダイアログが出てしまう不具合を修正**しました。
  Finder や `open -a` で渡されたパスは、画面の準備ができてから確実に開きます
- Dock のアイコンをもう一度クリックすると、ウィンドウが前面に出ます
- 起動中のアプリに別のファイルを渡すと、プロセスを増やさず既存ウィンドウで開きます
  （最小化・背面でも前面に出ます）

### 2. `.txt` を開いて編集したとき、保存も `.txt` のまま

- `.txt` を開いて **書式ツールバーを使わずに** 保存した場合、拡張子は `.txt` のままです
- 書式ツールバー（太字・見出し・表など）で Markdown 記法を追加した場合だけ、
  保存前に「.md で保存 / .txt のまま保存 / キャンセル」を確認します
- `.txt` を開いている間は、画面下に「このファイルはテキスト（.txt）です」と案内します
- 保存ダイアログの推奨名とフィルタも書類の種類に合わせます

### 3. 上部ツールバーの縦幅

- ツールバーの高さを **従来の 0.9 倍** にしました（72px → 64.8px、狭い画面も同率）
- ウィンドウの **横幅** に応じた段階の切り替えが、**なめらかに** 変わるようになりました
  （180ms のイージング）
- さらにウィンドウの **縦幅** に応じて **1.0 倍〜0.8 倍** の係数を掛けます
  （高さ 900px 以上で 1.0、360px で 0.8、その間は連続的に変化）
- 書式ツールバーも同じ比率で追従します

### その他

- 日本語・英語をはじめ 5 言語の文言を 186 キーに拡充。画面に残っていた未翻訳の
  日本語（PDF 余白ラベル、設定の「テキスト」、検索欄、書式ボタンの説明など）を解消しました
