# MD Viewer Pro v26.1.1 — v1.5.3 デザイン整合

UI を v1.5.3 の見た目に寄せた更新版です。旧版の紹介動画から実画面を抽出し、配色・寸法・操作感を比較して調整しました。

## 変更点

- ツールバーを **72px のフラットなテキストバー**に変更（角丸ボタン・青い主要ボタンを廃止）
- グループ間の**縦区切り線**、選択項目は**灰色のブロック**表示（v1.5.3 と同じ）
- スケールをセレクトから**スライダー + % 表示**へ
- 書式ツールバーを 52px のフラット表示に統一
- エディタの**行番号を廃止**（v1.5.3 の TXT編集と同じ）
- **目次パネルは編集時のみ**表示（閲覧時は全幅）
- ウィンドウタイトルに文書名を表示
