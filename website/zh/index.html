一份文档，三种工作方式

阅读。整理。交付。

从打开文件到导出成品，让 Markdown 工作流始终连贯。

01

舒适阅读

以清晰、易导航的版式呈现标题、代码、表格、图片与 YAML 前置元数据。

02

即时编辑

可直接编辑渲染后的文档，也可使用左右分栏与实时预览的 TXT 编辑模式。

03

如实导出

支持 A4、B5 文档布局，并可将当前效果导出为 PDF 或 HTML。

真实应用界面

让 Markdown 成为完整文档。

这是应用的实际界面。顶部栏可切换阅读、MD 编辑、TXT 编辑，并控制布局、缩放、目录和 PDF 导出。

0公式渲染所需网络

只保留文档工作真正需要的功能。

01离线数学公式

无需额外安装即可排版 LaTeX 行内公式、独立公式、矩阵和分数，并保留到导出文件中。

$E = mc^2$

02离线绘制图表

内置完整的 mermaid.js，将 ```mermaid 代码块渲染为流程图、图表，无需联网。

A --> B

03按结构导航

目录面板默认开启，可浏览所有标题并快速跳转。

H1 H2 H3

04保留输入的换行

按一次 Enter 即显示换行，也可随时恢复标准 Markdown 行为。

↵ = 换行

05支持 YAML

前置元数据以信息面板呈现，.yml 和 .yaml 文件支持语法高亮。

--- title:

06字体与主题

可添加 TTF、OTF、TTC 字体，并通过 JSON 插件主题扩展显示效果。

Aa + { }

07按页面整理

支持自由、A4、B5 布局、页边距设置与 LaTeX 分页命令。

A4 / B5

首次启动出现警告时

当前公开版本采用临时签名，未经 Apple 公证。若提示“已损坏”，应用本身并未损坏。请先将 MDViewerPro.app 放入应用程序文件夹（不要在 DMG 内直接打开），在终端运行 xattr -cr /Applications/MDViewerPro.app 后再打开。仍无法打开时，请在“系统设置 → 隐私与安全性”中允许打开。
