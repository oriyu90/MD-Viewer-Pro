If macOS warns on first launch

The current public release is ad-hoc signed and not Apple-notarized. If macOS says the app is damaged, the app itself is not damaged. First put MDViewerPro.app into the Applications folder (do not open it inside the DMG), run xattr -cr /Applications/MDViewerPro.app in Terminal, then open it. If it still won't open, allow it in System Settings → Privacy & Security.

If SmartScreen appears

The Windows build is unsigned, so SmartScreen may say "Windows protected your PC". The app itself is not damaged. Choose "More info" → "Run anyway". Unblocking the ZIP with unblock-File before extracting avoids the warning.
