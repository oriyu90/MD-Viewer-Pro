ONE DOCUMENT, THREE WAYS TO WORK

読む。整える。届ける。

ファイルを開いた瞬間から、完成した文書を書き出すまで。Markdown の流れを止めません。

01

美しく読む

見出し目次、コードハイライト、表、画像、YAML フロントマターを、落ち着いたレイアウトで表示します。

↘
02

その場で直す

レンダリングされた文書を直接整える MD編集と、左右分割のリアルタイムプレビューを備えた TXT編集。

↘
03

見たまま届ける

A4・B5の文書レイアウトに対応。画面の仕上がりを保ったまま PDF / HTML へ書き出せます。

↘

THE REAL APPLICATION

Markdown が、文書として立ち上がる。

添付の実画面。上部バーから閲覧・MD編集・TXT編集を切り替え、レイアウトや拡大率、目次、PDF書き出しを操作できます。

3作業モード
5アプリ表示言語
0数式表示のネット接続

文書づくりに必要なものだけ。

01数式を、オフラインで

LaTeX のインライン・別行数式、行列や分数を追加インストールなしで組版。PDF / HTML にも反映します。

$E = mc^2$

02図も、オフラインで

```mermaid フェンスのフローチャートやグラフを、mermaid.js 完全同梱で図として描画。ネット接続は不要です。

A --> B

03見出しから迷わない

標準オンの TOC パネルで文書全体を把握。見出しを選ぶだけで、その場所へ移動できます。

H1 H2 H3

04書いた改行を、そのまま

Enter で入れた単一改行をそのまま表示。必要なら標準 Markdown の挙動へ戻せます。

↵ = line break

05YAML も、文書の一部

フロントマターはメタ情報パネルとして表示。.yml / .yaml ファイルも構文強調付きで開けます。

--- title:

06自分の書体とテーマ

TTF / OTF / TTC を本文フォントとして追加。JSON のプラグインテーマで表示も拡張できます。

Aa + { }

07ページを意識して整える

A4・B5・フリー表示、余白設定、LaTeX の改ページコマンドに対応しています。

A4 / B5

APP LANGUAGES
